# Research Source Plan for Final SWE7303 Report

The assessment brief requires approximately 15–20 secondary sources at HE7 level, with at least four refereed academic journals and five academic books. The project repository does not fabricate those references.

Build the final bibliography from independently verified sources covering:
- DevOps culture and continuous delivery;
- microservices architecture and distributed-system trade-offs;
- CI/CD quality gates and deployment automation;
- containerisation and software supply-chain security;
- infrastructure as code;
- AWS/cloud-native architecture;
- observability and SRE concepts;
- DevSecOps;
- blue-green/zero/minimal-downtime deployment and rollback;
- ML operations/model governance;
- retrieval-augmented hosted LLM systems, API dependency trade-offs and responsible AI.

For technical implementation facts, also retain official primary documentation for Docker, Jenkins, AWS, Terraform and Hugging Face. These official sources are useful technical evidence but do not replace the brief's required refereed journals/books.

For every candidate academic source verify author, title, publisher/journal, year, DOI/ISBN and relevance before adding it. The report should critically compare tools/strategies rather than attaching one citation to a purely descriptive list.
