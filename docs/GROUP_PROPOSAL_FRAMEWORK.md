# Week 7 Group Proposal Framework

- Project: CampusPulse AI — AI-Powered Campus Feedback & Issue Management Platform.
- Business problem: provide a traceable online campus issue workflow while demonstrating cloud-native DevOps delivery.
- Core scope: role-based web app, feedback CRUD/workflow, local AI triage, local Hugging Face assistant, PostgreSQL, notifications, analytics, test automation, containers, AWS deployment and observability.
- Out of scope for mandatory implementation: Kubernetes/EKS, paid hosted LLM APIs, production institutional identity federation.
- Architecture diagram: use `docs/diagrams/overall-system.mmd`.
- Delivery plan: local implementation → tests → Compose → Jenkins → ECR/RDS/Beanstalk → monitoring → blue-green → rollback → evidence.
- Role allocation: add member names/college IDs only in the group-controlled proposal, with explicit ownership of frontend, backend/data, AI/LLM, CI/CD/cloud, QA/security/documentation and integration. Do not invent participation.
