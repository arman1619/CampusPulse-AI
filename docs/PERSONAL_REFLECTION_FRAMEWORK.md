# Personal Reflection Evidence Framework

The SWE7303 brief assigns substantial marks to personal reflection and role. This file intentionally does **not** fabricate a first-person reflection.

For each student, record verifiable evidence under these headings:
1. **Allocated responsibilities** — tasks agreed by the group and dates/issue IDs.
2. **Technical contribution** — commits, PRs, Jenkins runs, AWS actions, tests or documentation personally completed.
3. **Problem encountered** — a concrete failure/constraint, diagnosis and evidence.
4. **Decision and trade-off** — alternatives considered and why one was selected.
5. **Learning against LO1–LO3** — what changed in the student's understanding of implementation, strategy and tool selection.
6. **Personal limitation/mistake** — what could have been done differently.
7. **Future professional practice** — a specific improvement, not generic reflection language.

Attach commit hashes, screenshots, ticket IDs and meeting records where available. Reflection should remain truthful, individual and written by the student.
